# طريقة فتح وبناء PineLab في Code Assist

1. نزّل المستودع كملف ZIP من GitHub، ثم فك الضغط.
2. افتح مجلد `PineLab` نفسه في Code Assist، وليس مجلد المستودع الأعلى.
3. انتظر مزامنة Gradle.
4. إذا طلب تنزيل Android Gradle Plugin أو Kotlin Plugin فاسمح بذلك عند توفر الإنترنت.
5. نفّذ Build APK من قائمة البناء.

## ملاحظات

- المشروع يستخدم Android Gradle Plugin 8.6.1 وKotlin 2.0.20 وJava 17.
- لا يحتاج التطبيق إلى صلاحية الإنترنت أثناء التشغيل.
- الواجهة الحالية مرحلة تأسيسية: تعرض شارت شموع اصطناعية ومحرر نصوص وحفظاً محلياً وإعادة تشغيل مبسطة.
- زر «فحص وتشغيل» لا ينفّذ Pine فعلياً بعد. محرك Pine v5/v6 قيد الدمج والاختبار، ولن نعلن دعماً غير متحقق منه.
- أول مزامنة Gradle قد تحتاج اتصال إنترنت لتنزيل أدوات البناء؛ هذا منفصل عن عمل التطبيق بعد تثبيته.
